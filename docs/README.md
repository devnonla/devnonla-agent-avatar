# Agent avatar docs (local)

Docs for `devnonla-agent-avatar`. `/` opens Introduction. Each page is a markdown file under `pages/` with frontmatter (`path`, `title`, `group`). The sidebar and routes come from those files.

```bash
cd docs && bun run dev
```

http://localhost:5177/

Published: https://devnonla.github.io/devnonla-agent-avatar/

| Path | Page |
| --- | --- |
| `/` | Redirects to `/introduction` |
| `/introduction` | Get started |
| `/installation` | Install |
| `/devnonla-avatar` | DevNonlaAvatar |
| `/shape-avatar` | AgentShapeAvatar |
| `/animal-avatar` | AgentAnimalAvatar |
| `/agent-body` | Agent body |

Old hashes (`#/chat/avatar`, `#/agent-body`) and `/docs/…` redirect to the current paths.
